# ANSI SQL Using MySQL

## Project Overview

This project is based on an Event Management System database developed using MySQL. The database manages users, events, sessions, registrations, feedback, and resources.

## Database Schema

The project contains the following tables:

1. Users
2. Events
3. Sessions
4. Registrations
5. Feedback
6. Resources

## Files Included

### schema.sql
Contains:
- Database creation
- Table creation
- Primary Keys
- Foreign Keys
- Constraints

### sample_data.sql
Contains:
- Sample records for all tables
- Test data for query execution

### solutions.sql
Contains solutions for:
- User Upcoming Events
- Top Rated Events
- Inactive Users
- Peak Session Hours
- Most Active Cities
- Event Resource Summary
- Low Feedback Alerts
- Sessions per Upcoming Event
- Organizer Event Summary
- Feedback Gap
- Daily New User Count
- Event with Maximum Sessions
- Average Rating per City
- Most Registered Events
- Event Session Time Conflict
- Unregistered Active Users
- Multi-Session Speakers
- Resource Availability Check
- Completed Events with Feedback Summary
- User Engagement Index
- Top Feedback Providers
- Duplicate Registrations Check
- Registration Trends
- Average Session Duration per Event
- Events Without Sessions
