# CSS3 Final Project
## Local Community Event Portal

This project demonstrates all CSS3 concepts required in the assignment.

### Covered Topics

1. Inline, Internal and External CSS
2. CSS Syntax and Comments
3. Selectors
   - Universal Selector
   - Element Selector
   - ID Selector
   - Class Selector
   - Grouping Selector

4. Colors and Backgrounds
   - HEX Colors
   - RGBA Colors
   - Background Images
   - Linear Gradients

5. Typography
   - Google Fonts
   - Font Family
   - Font Size
   - Font Weight
   - Text Alignment
   - Letter Spacing
   - Line Height

6. Links and Lists
   - :link
   - :hover
   - :active
   - :visited
   - list-style-type
   - list-style-position

7. Tables
   - Borders
   - Padding
   - Zebra Striping
   - Border Collapse

8. Box Model
   - Margin
   - Padding
   - Border
   - Outline
   - visibility:hidden
   - display:none

9. Multi Column Layout

10. Responsive Design
    - Media Queries
    - Flexible Layouts

11. DevTools Testing
